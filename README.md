📌 Project Description

Recipe Book with Categories is a web development project created to make recipe browsing easier. It organizes recipes into categories so users can find dishes without searching through a long list.

The project focuses on a clean layout, simple navigation, and an engaging user experience.

💻 How to Run Locally

Clone the repository:

git clone https://github.com/satyamshuklaSS07/Recipe-Book-with-Categories.git

Open the project folder.

Open index.html in your browser, if the project uses a static HTML setup.

🎤 Interview Questions and Answers

Q1. What is the main purpose of your project?

Answer:
The main purpose of my project is to organize recipes by category and make it easy for users to find and explore different dishes.

Q2. Which technologies did you use in this project?

Answer:
I used HTML to create the structure, CSS to design the layout, and JavaScript to add interactive features.

Q3. How does category filtering work?

Answer:
Each recipe is connected to a category. When a user selects a category, the application displays recipes that belong to that category.

Q4. What challenges did you face while developing this project?

Answer:
One challenge was organizing recipes and making the interface easy to use. I worked on the layout and functionality to make recipe browsing simpler.
